Grandeurs calculées

Syntaxe des calculs
  • Une ligne par grandeur : nom (unité) = expression. L’unité est facultative.
  • Une expression sans variable définit une constante : g (m/s²) = 9.81.
  • Opérations : + - * / ^, sqrt, exp, ln, log10, sin, cos, tan, asin, acos, atan, abs, pi. Point décimal : 0.5.
  • Angles : le réglage Angles en degrés / en radians s’applique à sin, cos, tan et à leurs inverses, dans les calculs, les incertitudes et les modèles. On peut aussi préciser l’unité d’une valeur : sin(30 deg), cos(1.2 rad).
  • deriv(y, t) : dérivée de y par rapport à t. integ(y, t) : intégrale cumulée.
  • mean(x), min(x), max(x), std(x), sum(x) s’appliquent à toute la colonne.
  • L’incertitude d’une variable peut être un nombre (0.05) ou une formule (0.02*U + 0.01).
  • Unités : m^3 s’affiche m³, m/s^2 m/s², mol.L^-1 mol.L⁻¹. Un nombre peut s’écrire 2.5e-7 ou 2.5×10^-7 (virgule acceptée dans le tableau et les champs).
